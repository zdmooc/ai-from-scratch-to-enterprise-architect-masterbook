# Volumes de la Bible IA

Ce répertoire contient les 24 livres en **état de planification initiale**. Chaque volume possède un `index.qmd`, accompagné à terme de chapitres QMD, exercices corrigés, figures et laboratoires. Le catalogue canonique est `../catalog/volumes.json`.

Le mot **PLANNED** dans les index signifie que le livre **n'est pas écrit**. Le fichier `chapters/01-...qmd` du volume 01, s'il existe, est une **ébauche pédagogique** et non une preuve de publication.

Prévisualiser un volume : `python scripts/build_volume.py --volume 01 --format html`. Voir `publishing/README.md`.
